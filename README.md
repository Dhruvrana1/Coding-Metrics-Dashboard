# Coding Metrics Dashboard 📊

A frontend project built using HTML, CSS, and JavaScript to display coding problem-solving statistics.  
This project is inspired by coding platforms and focuses on practicing JavaScript logic and DOM manipulation.

---

## 🚀 Features
- Displays coding metrics such as Easy, Medium, and Hard problem counts
- Calculates and shows total problems solved
- Dynamically updates UI using JavaScript
- Clean and beginner-friendly interface

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
